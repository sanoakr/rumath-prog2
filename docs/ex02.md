### 演習課題 ex02-1 — aiJudge にプログラムを提出する {: .exercise }

第01回は aiJudge に画像を提出しました。今回からは C 言語のプログラム（ソースコード）を提出します。

aiJudge は提出されたソースコードをコンパイル・実行し、用意した入力に対して正しく出力できたかを自動で採点します。
結果の読み方は [aiJudge 学生向けガイド](https://sanoakr.github.io/aijudge/student/) の「結果を読む」を参照してください。

まず練習として、コース内の ex02 にある簡単な問題から取り組んでください。提出は何度でもできます。
自分の C 言語環境でコンパイルと動作確認を済ませてから、**実行ファイルではなくソースコードを**提出してください。

今回の問題セットには、次の課題があります。

<!-- aijudge:begin ex02 -->
- hello.c
- hello2.c
- prime.c
- 採点が後で始まる課題（提出練習）
- 整数の入力と出力
- 整数の正負
- カウントダウン
- カウントアップダウン
<!-- aijudge:end -->

### 演習課題 ex02-2 — 今回課題の提出条件をクリアする {: .exercise }

各回の演習問題セットは、得点の合計が 100 点以上になればクリアです。
配点は問題ごとに異なり、やさしい問題は低く、むずかしい問題は高く設定しています。
どの問題に取り組むかは各自で選んでください。やさしい問題を順に解いても、むずかしい問題を中心に解いても 100 点に届きます。

!!! note "提出は何度でもできます"
    aiJudge は提出のたびに自動で採点します。満点になるまで何度提出しても構いません。
    ただし「採点が後で始まる課題（提出練習）」だけは、採点開始（10/1 18:00）まで結果が表示されません。

**今回の演習問題セット「ex02」で 100 点以上を取ってください。**
