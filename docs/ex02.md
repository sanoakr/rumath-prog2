### 演習課題 ex02-0（未完了の人のみ） {: .exercise }

[第01回 ex01](ex01.md) の C 言語プログラミング環境の構築がまだの人は、先にそちらを済ませてください。
すでに構築済みの場合は、この課題に取り組む必要はありません。

### 演習課題 ex02-1 — aiJudge にプログラムを提出する {: .exercise }

**第01回では aiJudge に画像を提出しました。今回からは、C 言語のプログラム（ソースコード）を提出します。**

1. 提出したソースコードは、aiJudge が自動でコンパイル・実行し、用意された入力に対する出力が正しいかを自動採点します。
   結果の読み方は [aiJudge 学生向けガイド](https://sanoakr.github.io/aijudge/student/) の「結果を読む」を参照してください。
2. まず練習として、コース内の **ex02** に用意された簡単な問題から取り組んでください。
3. 提出は何度でもできます。まずは自分の C 言語環境でコンパイル・動作確認をしてから、
   ソースコード（実行ファイルではない）を提出してください。

今回の問題セットに含まれる課題:

<!-- aijudge:begin ex02 -->
- hello.c
- hello2.c
- prime.c
- 採点が後で始まる課題（提出練習）
- 整数の入力と出力
- 整数の正負
- カウントダウン
- カウントアップダウン
<!-- aijudge:end -->

### 演習課題 ex02-2 — 今回課題の提出条件をクリアする {: .exercise }

- 各回の演習問題セットは、得点合計が **100点以上** になることがクリア条件です。
- 問題ごとに配点があります（やさしい問題は低く、むずかしい問題は高く）。どの問題に取り組むかは各自で選べます。
  やさしい問題を順に解いても、むずかしい問題を中心に解いても 100 点に届きます。

!!! note "提出は何度でもできます"
    aiJudge は提出のたびに自動採点します。満点になるまで何度でも提出して構いません。
    ただし「採点が後で始まる課題（提出練習）」だけは、採点開始（10/1 18:00）まで結果が出ません。

**今回の演習問題セット「ex02」で 100 点以上をクリアしてください。**
