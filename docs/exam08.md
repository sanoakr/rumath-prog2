# exam08 — プログラミング試験（小テスト）

## 小テスト（プログラミング試験） {: .exercise }

1-609 で、aiJudge を使ったオンラインのプログラミング試験（小テスト）を実施します。

- 日時: 11月12日（木）4-5講時（第08回）15:30〜17:30（2 時間）
- 場所: 1-609（対面。自分の PC または実習室 PC で受験）

1. aiJudge 上の試験課題 exam08 に、aiJudge の Web エディタで解答してください（コースの画面で exam08 の
   「エディタで解く」を押します）。試しの実行も Web エディタで行ってください。
   ファイルでは提出できません。自分の演習課題などの既存のコードを Web エディタに貼り付け、修正して解答に使うことはできます。
2. プログラミング試験の実施時間は 2 時間です。
3. 試験中に使えるモニタは 1 台だけです。実習のときのように、実習室のモニタをノート PC の外部ディスプレイとして使うことはできません。仮想デスクトップで複数のデスクトップを切り替えるのは構いません。
4. 実習室 PC で受験する場合は、自分の演習のソースコードなどを実習室 PC で使えるように準備しておいてください。
5. 自分のソースファイル・ネット検索・書籍資料は参照できます。
6. 他者や生成 AI とのやり取り（会話・チャット・SNS・ファイル送付、ChatGPT・Gemini など）は禁止です。別のタブやアプリで生成 AI サービスを使うことも不正行為になります。
7. 試験中は、PC の操作や aiJudge への提出も含めて、TA のサポートを受けられません。
8. 問題はすべて選択問題です。すべての問題を提出しても、1 問も提出しなくても構いません。問題は難易度順に並んでいません。問題文を読んで、解く問題を自分で選んでください。
9. 各問題は 10 点満点です。この試験の総点は、50 点を上限として成績に反映します。コンパイルできないソースファイルは採点されません。
   問題には、出力の正しさに加えて、「`if` や配列を使わない」「`// ここから` と `// ここまで` の間だけを書く」「直した行の末尾に `// 修正` を付ける」「`//` の行に説明を書く」などの条件が付くものがあります。これらの条件を満たしていないと、出力が正しくても点が付きません。
10. Web エディタは、解答を作る過程（打鍵・貼り付け・実行・提出など）を時刻付きで記録します。記録を見られるのは
    担当教員だけです。提出されたコードは機械的に類似度をチェックし、疑わしいときはこの記録で作成過程を確認して、
    必要なら口頭試問を行います。生成 AI によるコードもチェックの対象です。**コピーや生成 AI の利用などの不正が
    認められた場合は、学則に従い、不正行為として扱います。**
11. Web エディタは、書いた内容を 10 秒ごとに自動保存します。ブラウザが落ちても、開き直せば続きから書けます（別の PC からでも可）。
    試験終了の時点で最後に保存された内容を、aiJudge が自動で提出します。
12. aiJudge は試験中、提出をすぐには採点しません。**終了 20 分前（17:10）**に採点を始め、それまでに提出されたコードを
    まとめて採点します。それ以降の提出はすぐに採点します。この結果をもとに、必要に応じて
    試験終了までにコードを修正して再提出してください。試験終了（17:30）の後は提出できません。
