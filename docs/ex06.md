### 演習課題 ex06 {: .exercise }

今回の問題セットには、次の課題があります。

- 配列要素のうち3と5の倍数

- 歯抜けの掛け算九九表

### プログラミング試験の準備 {: .exercise }

ex06 の問題は、ファイルの提出に加えて、aiJudge の Web エディタでも解答・提出できます。
次回の ex07（模擬試験的演習）と第08回のプログラミング試験（小テスト）は、Web エディタからしか提出できません。
小テストを受けるために、今回のうちに自分の環境で Web エディタの動作と操作方法を十分に確認してください。

1. **Web エディタで受験する準備と確認**

   プログラミング試験では、aiJudge の Web エディタで解答・提出します。試験で使う PC とブラウザで aiJudge に
   ログインし、Web エディタが使えることを確認してください。小テストで実習室 PC などを使う可能性がある人は、
   実際に使う PC で確認し、自分の演習のソースコードなどをその PC で使えるように準備しておいてください。
   試験中に使えるモニタは 1 台だけです。実習のときのように、実習室のモニタをノート PC の外部ディスプレイとして
   使うことはできません（仮想デスクトップで複数のデスクトップを切り替えるのは構いません）。使い方は [aiJudge 学生向けガイド](https://sanoakr.github.io/aijudge/student/)
   の「エディタで解く問題セット」を参照してください。

   試験が始まった後は、aiJudge などの PC 操作について質問できません。次回までに、TA サポートなどを利用して
   受験環境を事前に整えておいてください。

2. **生成 AI は利用できません**

   プログラミング試験（小テスト）では、生成 AI もコーディング AI も利用できません。別のタブやアプリで
   生成 AI サービスにアクセスすることも不正行為です。解答は Web エディタ上で書いてください。自分の演習課題などの
   既存のコードを貼り付け、修正して解答に使うことはできます。Web エディタは、打鍵・貼り付け・実行・提出などの操作を
   時刻付きで記録します。

3. **ex06 の問題を Web エディタで解く（練習）**

   コースの画面で ex06 の「エディタで解く」を押し、少なくとも 1 問（たとえば「配列要素のうち3と5の倍数」）を
   Web エディタだけで解いてください。ソースコードの入力、試しの実行（標準入力を与えた動作確認）、デバッグ、提出まで、
   本番と同じ手順で一通り操作できることを確認してください。
