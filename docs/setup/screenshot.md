# PC 画面のスクリーンショットを撮る

### Windows

**Windows キー + Shift + S** を同時に押すと、画面上部にスクリーンショットを撮影するためのメニューが表示されます。 デスクトップ、ウィンドウ、指定領域などの単位で撮影領域を指定することができます。

詳しくは、マイクロソフトの公式ドキュメント「[**Snipping Tool を使ってスクリーン ショットをキャプチャする**](https://support.microsoft.com/ja-jp/windows/snipping-tool-を使ってスクリーン-ショットをキャプチャする-00246869-1843-655f-f220-97299b865f6b)**」**読んで下さい。

### macOS

**Shift + Command + 5** を同時に押すと、画面下部にスクリーンショットを撮影するためのメニューが表示されます。 デスクトップ、ウィンドウ、指定領域などの単位で撮影領域を指定することができます。

詳しくは、Apple の公式ドキュメント「[Macでスクリーンショットを撮影する/画面を収録する](https://support.apple.com/ja-jp/guide/mac-help/mh26782/mac)」を読んで下さい。
