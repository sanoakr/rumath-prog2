# PCのデスクトップ録画

プログラミング試験用のデスクトップ録画環境を準備します。

試験に利用するPCのWebブラウザから、デスクトップ画面を記録することで、オンライン試験中の不正行為を防止し、公正に受験していることの証明とします。

オンライン試験では、デスクトップ録画の録画データ、またはその共有リンクを提出することで受験したと認められます。オンラインでの受験を行う場合は、上記のページを参考にしてデスクトップ画面をきちんと録画できることを確認し、また、録画データやリンクを提出できるように準備して下さい。

オンライン試験では、受験するPCの性能やディスク残量に合わせて、以下のいずれかの方法を用いてPCのデスクトップ録画を作成して下さい。

1. [**デスクトップ録画ツール（独自）**](#desktop-record-tool) **← 特別な事情が無ければこちらをおすすめ**
    - PCのローカル環境に録画データが保存され、保存した録画ファイルを提出します。
    - PC上で比較的多くのメモリとディスク容量（約10MB/分、1GB/時間）を必要とします。
    - 録画時間に制限はありません。2時間を1つの録画ファイルとして提出できます。

2. [**Vimeo Record でのクラウドデスクトップ録画**](#vimeo-record) **（短時間の制限あり、非推奨）**
    - クラウド上に録画データが保存されます。録画データへのリンクを提出します。
    - クラウドに保存されるため、メモリとディスクの利用量は少なめです。
    - 録画時間に30分の上限があります。複数回の録画操作を行う必要があります。

比較的新しいPCで、8GB以上のメモリを搭載しており、ディスク容量に数十GB以上の空き容量があれば、いずれの方法でも利用できると思います。ちょっと古い8GBメモリのWindowsノートPC（SurfaceProX, 2020年発売）では、2時間のデスクトップ録画も問題なく終了しました。より古かったりメモリやディスク残量が少ない場合は、Vimeo Record でのクラウド録画も検討してください。

### デスクトップ録画ツール（独自） { #desktop-record-tool }

- [デスクトップ録画ツール](https://elite.math.ryukoku.ac.jp/desktoprecord.html)

![画像](../assets/setup/screen-recording/img01.png)

録画開始ボタンを押すと録画画面の選択ページが表示されます。プログラムを作成するデスクトップ画面全体を選択すると録画が開始されます。録画停止ボタンを押すと録画が停止され、録画されたファイルをダウンロードできます。再度、録画開始ボタンを押すと新しいデスクトップ録画が開始されます。

録画ファイルのサイズは、1分あたり約10MBの大きさになります。2時間の録画では2GBを超えるファイルサイズとなることがあります。PCのディスク容量を確認し、残量が厳しそうな場合は、以下の Vimeo Record を利用することも検討して下さい。

### Vimeo Record でのクラウドデスクトップ録画 { #vimeo-record }

オンラインのデスクトップ録画サービスです。録画データはクラウド上に保存され、その録画リンクを提出することで、PCのディスク容量を消費せずに録画提出が可能です。

一方で、無料アカウントでは録画時間の上限が30分となっています。30分を超えるデスクトップ録画を行う場合は、30分ごとに新たな録画を繰り返して複数の録画リンクを提出する必要があります。

詳しい利用方法は、[Vimeo Record でのクラウドデスクトップ録画](vimeo-record.md)にあります。
