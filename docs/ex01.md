講義パートでも説明した（はず）ように、ここでは各 OS の標準的な C 言語プログラミング環境を各自で構築します。

数理課程の独自環境で C 言語プログラミングを体験しました。この科目では 2 年次以降の科目でも利用する
各 OS 標準の方法で、より一般的な C 言語プログラミング環境を各自の PC 上に構築します。
以下を参考にしながら、各自で C 言語開発環境を構築してください。

コンパイルから実行までの流れは [簡単な C プログラムをコンパイル・実行してみる](setup/c-hello.md) が参考になります。

### ex01-2 ターミナル操作の練習（WebTerm Learn 修了証） {: .exercise }

この科目では、ターミナル（端末）と呼ばれるコマンドベースのインターフェイス（CUI）を用いて、
ファイルの操作や C プログラムのコンパイル・実行などを行います。

[WebTerm Learn でターミナル操作を練習する](https://sanoakr.github.io/rumath-prog2/setup/webterm/) を参考に、
オンラインの学習サイト [WebTerm Learn](https://learn.webterm.app/ja) の
「**根の森 — ターミナル入門編**」のレッスンをすべて修了してください。

- 修了すると「ダッシュボード」から**修了証（Certificate of Completion）** を PNG でダウンロードできます。
- **ダウンロードした修了証の PNG 画像を、この課題に提出**してください。

**修了証を取得する前に、ユーザー名を学籍番号を含むものに変更してください。**
修了証には修了した時点のユーザー名がそのまま印刷されます。サインイン直後は Google / GitHub
アカウントの本名になっているので、レッスンを始める前に「アカウント設定」で変更しておいてください
（変更方法は
[WebTerm Learn でターミナル操作を練習する](https://sanoakr.github.io/rumath-prog2/setup/webterm/)
の Step 2 を参照）。

- **学籍番号が含まれていない修了証は減点されます。**
- **一度発行された修了証の名前は、あとから変更できません。**
- 学籍番号の入っていない修了証を発行してしまった場合は、ユーザー名を変更したうえで
  続きのコース「**ターミナル基礎編**」に取り組み、そちらの修了証を提出することができます。

参考: [Unix/Linux コマンドリファレンス（日本語チートシート, PDF）](https://kanemotilevel.com/wp/gazou/unix.pdf)

### ex01-3 paiza ラーニング「新・Linux入門編（LinuC対策版）」 {: .exercise }

[paiza ラーニング](https://paiza.jp/works/) は、環境構築不要でブラウザだけでプログラミングを学べる学習サイトです。
この科目では、教育機関向けに発行される「学校フリーパス」の**クーポンコード**を使うことで、
（本来は有料の）すべての講座を無料で受講できます。

[paiza ラーニングでクーポンコードを使う](https://sanoakr.github.io/rumath-prog2/setup/paiza-coupon/) を参考に、
paiza ラーニングのユーザー登録とクーポンコードの登録を行ってください。

- クーポンコードは **Teams の科目チーム**で案内します。
- 登録時のニックネームには、**必ず自身の学籍番号を含めて**ください（認定証のユーザー名表示に使われます）。

#### 課題: 新・Linux入門編（LinuC対策版）に取り組む

paiza ラーニングの [「**新・Linux入門編（LinuC対策版）**」（全 14 レッスン）](https://paiza.jp/works/linux/new-primer) に取り組んでください。
修了したレッスンの認定証の画像を、この課題に提出してください。

- 得点率は、**1 回の提出に含まれる、異なるレッスンの認定証の枚数**で決まります（1 枚で 50%、2 枚で 80%、3 枚以上で 100%）。
- 複数のファイルを同時に提出できます。認定証の画像は**まとめて 1 回で提出**してください。
- あとからレッスンを追加したときは、それまでの認定証も含めて全部を提出し直してください。
