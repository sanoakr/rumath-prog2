## 第 01 回の演習課題 {: .exercise }

講義パートで説明したとおり、この科目では OS 標準の C 言語プログラミング環境を各自の PC 上に構築します。

前期の「プログラミング及び実習1（中野）」では、初学者が理解しやすいように、タートルグラフィックスを使う数理課程の独自環境で C 言語プログラミングを体験しました。この科目では、2 年次以降の科目でも使う Windows や macOS の標準環境を使います。
以下を参考に、各自で C 言語開発環境を構築してください。

この科目では、課題の提示と提出をすべて [aiJudge](https://judge.math.ryukoku.ac.jp/)（オンラインジャッジ）で行います。
aiJudge には龍谷大学の全学認証でログインします。使い方は [aiJudge 学生向けガイド](https://sanoakr.github.io/aijudge/student/) を参照してください。

### ex01-1 C 言語プログラミング環境の構築 {: .exercise }

OS の標準的な C 言語プログラミング環境を、自分の PC 上に構築してください。ターミナルで `cc` コマンドを実行できれば完了です。

- Windows: [Windows への WSL の導入と日本語化](https://sanoakr.github.io/rumath-prog2/setup/wsl-install/)
  → [Ubuntu Linux の C 言語開発環境](https://sanoakr.github.io/rumath-prog2/setup/ubuntu-c/)
- macOS: [macOS の C 言語開発環境](https://sanoakr.github.io/rumath-prog2/setup/macos-c/)

環境を構築したら、`cc` コマンドを実行した**ターミナルウィンドウのスクリーンショット画像**を撮影し、[aiJudge](https://judge.math.ryukoku.ac.jp/) のこの課題に提出してください。画像には `cc` コマンドの実行結果（エラーメッセージなど）が写っている必要があります。

各 OS でのスクリーンショットの撮り方は、[PC 画面のスクリーンショットを撮る](https://sanoakr.github.io/rumath-prog2/setup/screenshot/) を参照してください。

### ex01-2 ターミナル操作の練習（WebTerm Learn 修了証） {: .exercise }

この科目では、ターミナル（端末）と呼ばれるコマンドベースのインターフェイス（CUI）を使って、ファイルの操作や C プログラムのコンパイル・実行などを行います。

[WebTerm Learn でターミナル操作を練習する](https://sanoakr.github.io/rumath-prog2/setup/webterm/) を参考に、オンラインの学習サイト [WebTerm Learn](https://learn.webterm.app/ja) の「根の森 — ターミナル入門編」のレッスンをすべて修了してください。修了すると、「ダッシュボード」から修了証（Certificate of Completion）の PNG ファイルをダウンロードできます。ダウンロードした修了証の PNG ファイルを、この課題に提出してください。

**修了証を取得する前に、ユーザー名を学籍番号を含むものに変更してください。**
修了証には、修了した時点のユーザー名がそのまま印刷されます。サインイン直後のユーザー名は Google アカウントの本名なので、レッスンを始める前に「アカウント設定」で変更しておいてください（変更方法は [WebTerm Learn でターミナル操作を練習する](https://sanoakr.github.io/rumath-prog2/setup/webterm/) の Step 2 を参照）。

学籍番号が含まれていない修了証は減点します。一度発行された修了証の名前は、あとから変更できません。学籍番号の入っていない修了証を発行してしまった場合は、ユーザー名を変更したうえで続きのコース「ターミナル基礎編」に取り組み、そちらの修了証を提出してください。

参考: [Unix/Linux コマンドリファレンス（日本語チートシート, PDF）](https://kanemotilevel.com/wp/gazou/unix.pdf)

### ex01-3 paiza ラーニング {: .exercise }

[paiza ラーニング](https://paiza.jp/works/) は、環境構築なしにブラウザだけでプログラミングや機械学習などの IT 技能を学べる学習サイトです。この科目の履修生は、教育機関向けに発行される「学校フリーパス」のクーポンコードを使うと、本来は有料の講座もすべて無料で受講できます。

[paiza ラーニングでクーポンコードを使う](https://sanoakr.github.io/rumath-prog2/setup/paiza-coupon/) を参考に、paiza ラーニングのユーザー登録とクーポンコードの登録を行ってください。登録時のニックネームには、**必ず自分の学籍番号を含めてください**。ニックネームは認定証のユーザー名として表示されます。

#### 課題: paiza ラーニングの講座に取り組む {: .exercise }

paiza ラーニングの[「講座一覧」](https://paiza.jp/works/courses)から興味のある講座を自由に選んで取り組み、修了したレッスンの認定証の画像を提出してください。

得点率は、1 回の提出に含まれる、異なるレッスンの認定証の枚数で決まります（1 枚で 50%、2 枚で 80%、3 枚以上で 100%）。複数のファイルを同時に提出できるので、認定証の画像は**まとめて 1 回で提出**してください。あとからレッスンを追加したときは、それまでの認定証も含めてすべてを提出し直してください。
