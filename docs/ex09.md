# ex09 — 関数定義、プロトタイプ宣言

!!! warning "第 9 回から、指定した関数の定義も採点します"

    ex09 以降で、問題文が関数の定義を指定している課題では、**関数の定義**（10%）・**出力の正しさ**（45%）・**字下げ**（45%）の 3 つで採点します。

    - aiJudge は、提出したプログラムの関数を、別に用意した `main()` から直接呼び出して確かめます
    - 関数の名前・引数・返り値の型は、問題文の指定（プロトタイプ）どおりにしてください。関数が無い、型が違う、呼び出した結果が正しくない、のどれかに当たると、**出力が正しくてもその問題は 0 点**です
    - 関数の定義が正しくても、出力の正しさが 0% なら、字下げは採点しません（得点は関数の定義の 10% だけです）
    - 関数の定義を指定していない課題は、これまでどおり出力の正しさと字下げを半分ずつで採点します

!!! warning "不正行為として報告する場合"

    口頭試問で不正が確認された場合や、正当な理由なく呼び出しに応じなかった場合は、不正行為（後期の科目はすべて不合格）として教務課に報告します。コピーコードの配布元になった人も同じ扱いです。

### exam08 のフォローアップ提出 {: .exercise }

- aiJudge で exam08 の自己フォローアップ提出を受け付けます。受付期間は小テスト終了から 40 日間です。
- フォローアップ提出は 70% 引きで、各問 最大 3 点（配点 10 点の 30%）です。
- 小テストの受験者に限り、フォローアップの得点も含めて評価します。
- aiJudge は、各問への提出のうち最も点の高いもの（70% 引きの後の点で比べる）を自動で採用します。フォローアップで小テストの点が下がることはありません。
- フォローアップ提出の目的は自己学習です。コピーコードの提出が確認された場合は、学則に従い、不正行為として扱います。
- コピーコードのチェックでは、解答例や生成 AI によるコードなども対象とします。疑わしい場合は
  口頭試問を行うことがあります。
