# ex07 — 前半のまとめ（模擬試験的演習）

## プログラミング試験（小テスト）のための模擬試験的演習 ex07 {: .exercise }

この演習では、オンラインで実施するプログラミング試験（小テスト）と同じ形式で課題を出します。
第08回の小テストに備えて、aiJudge の Web エディタでの解答・提出を十分に練習しておいてください。

ex07 の問題は選択制です。aiJudge 上の演習課題 ex07 から、解く問題を選んで、Web エディタ（コースの画面の「エディタで解く」）で取り組んでください。問題は難易度順に並んでいません。問題文を読んで、解く問題を自分で選んでください。
試験と同じく、ex07 は Web エディタからしか提出できません（ファイルの提出はできません）。解答は Web エディタ上で書き、試しの実行もエディタで行います。

プログラミング試験の実施時間は 2 時間です。試験で使う PC とブラウザで、Web エディタでの解答・試しの実行・
提出ができることを確認しておいてください。プログラミング試験では生成 AI を利用できません。
別のタブやアプリで生成 AI サービスを使うことも不正行為になります。

ex07 の各問題は 10 点で、クリア条件は **20 点** です。

問題には、出力の正しさに加えて、次のような条件が付くものがあります。「`if` や配列を使わない」「`// ここから` と `// ここまで` の間だけを書く」「直した行の末尾に `// 修正` を付ける」「`//` の行に説明を書く」。これらの条件を満たしていないと、出力が正しくても点が付きません。問題文をよく読んでください。

ex07 では、プログラミング試験と同じく、aiJudge は提出をすぐには採点しません。11 月 5 日 16:30 から提出でき、17:00 に採点を始めて、それまでの提出をまとめて採点します。それ以降の提出はすぐに採点します。締切は同じ日の 18:30 です。締切の後も 11 月 11 日 12:00 まで提出できますが、70% を減点します。試験時間の 2 時間を想定して、締切までに、受験する PC 上で実行・動作確認・提出の手順を確認してください。

今回の問題セットには、次の課題があります。

<!-- aijudge:begin ex07 -->
- if を使わずに奇数と偶数を扱う
- 偶数だけ並び替え
- 隣接平均で平滑化
- 2回以上出現する値
- 出力の理由を説明する（型と演算）
- 空欄を埋める（増え続ける区間）
- 数字だけシーザー暗号
- 誤りを直す（最大値・最小値・平均値）
<!-- aijudge:end -->

    1-609 以外の場所（自宅など）からは受験できません。詳細は Teams の科目チームで案内します。
