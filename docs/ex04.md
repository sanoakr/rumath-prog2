# ex04 — 文字型、書式付き入出力、繰り返し処理、define マクロ、標準ライブラリ

!!! warning "第 4 回から、字下げ（インデント）も採点します"

    ex04 以降の課題では、提出したプログラムの**出力の正しさ**と**字下げ**を、半分ずつ（50% ずつ）で採点します。出力が正しくても、字下げが崩れていると、その問題の得点は最大で半分になります。

    - 各行を `{ }` の入れ子の深さどおりに字下げしてください。字下げの幅（2 スペース・4 スペース・タブなど）は自由ですが、ファイル全体でそろえてください
    - 崩れた行が 1 行も無ければ字下げは満点です。崩れた行が数えた行の 2 割以下なら字下げの点は半分、2 割を超えると 0 点になります
    - 出力の正しさが 0% のときは、字下げは採点しません（字下げの点も 0 点です）
    - 空行、`#include` などの行、コメントだけの行は数えません。タブとスペースを混ぜると、少ない側の行が崩れとして数えられます
